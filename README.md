# gridwork-systems

The static website of Gridwork Systems: https://gridworksystems.site

- Guides (31 articles), the product pages and the free tools - including the
  [Etsy fee calculator](https://gridworksystems.site/tools/etsy-fee-calculator.html) - are generated by
  `build.py` from the article sources.
- The four free workbooks in this repository are the only spreadsheets here; they are free downloads
  with no signup. Everything else is delivered through the store.

Built with AI assistance and checked with the tests in this project: every sold workbook is tested
with data entered, every price on the site is compared with the store, and the fee calculator's
arithmetic is run against worked examples.
